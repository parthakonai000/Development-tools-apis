# 🔌 API Collection

Welcome to the **API Collection**! This file contains a curated list of useful APIs for various development needs. This list will grow over time.

## 🌐 API List

| API Name | Description | Endpoint / Link |
| :--- | :--- | :--- |
| **Subdomain Search** | Searches for subdomains of a given apex domain. | `https://crt.name/v1/search?apex={your domain}` |
| **Ip address from details** | Here you can know location, sim operator, etc details with help of ip address. and you can know ip address from ip logger | `https://ipapi.co/{your ip address}/json/` |
